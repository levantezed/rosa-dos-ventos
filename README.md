# Rosa dos Ventos — Blog de Geografia (por Davi Levanteze)

Passo a passo completo de configuração na conversa. Resumo rápido:

1. Crie um projeto no Supabase e rode `supabase/schema.sql` no SQL Editor.
2. Copie `.env.example` para `.env` e preencha.
3. `npm install` e `npm start`.
4. Abra http://localhost:3000/api/health para testar a conexão.
5. Clique em "Entrar", use a senha do `.env` e publique.
